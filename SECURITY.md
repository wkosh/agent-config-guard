# Security policy

## Supported versions

Until version 1.0, only the latest released version receives security fixes.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue containing an undisclosed vulnerability, a real credential, private repository content, or personal data.

Include:

- Affected version and platform.
- A minimal reproduction using synthetic data.
- Expected and observed behavior.
- Security impact and suggested remediation, if known.

The maintainer aims to acknowledge complete reports within 72 hours, provide an initial assessment within seven days, and coordinate disclosure after a fix is available. These are response goals, not a bug-bounty offer or a guarantee of payment.

## Scope

Security issues in the parser, reporter, packaging, CI workflow, or documented safety properties are in scope. Findings produced by Agent Config Guard against third-party configuration should be reported to that project's maintainer, not here.
